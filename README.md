# 化学可视化 · 高中化学3D互动学习平台

> 免费 · 免安装 · 无需电脑基础 · 浏览器打开即用

**化学可视化**（小林的化学可视化网站）是一个面向高中生的全功能化学互动学习平台，把抽象的高中化学内容变成可旋转、可交互的 3D 模型，覆盖必修 + 选择性必修全部核心模块。

🌐 在线使用：**https://wujingxiaxiaolin.github.io/chem-viz/**

---

## ✨ 核心功能

| 模块 | 亮点 |
|---|---|
| 🧪 **3D 分子结构** | 常见无机物、离子、全部典型有机物；球棍/比例模型切换；σ键、π键、大π键、杂化方式、键角、空间构型、孤对电子、VSEPR |
| 💎 **晶胞与晶体** | 15 种高中经典晶胞（NaCl、CsCl、CaF₂、金刚石、石墨、SiO₂、干冰、体心立方、六方密堆积、ZnS、白磷、碘等）；**自由搭建晶胞**：任意放原子、成键、超胞延展、均摊切面数粒子、配位数、密度计算 |
| 🗺️ **元素周期表** | 全部 118 元素，电子排布图、电离能、电负性、化合价、焰色、递变规律 |
| ✏️ **有机化学** | 自由绘制有机结构式（积木拼图 + 自由手绘）、一键生成 3D 球棍模型、杂化自校正、官能团识别、同分异构体、反应机理动画 |
| ⚗️ **化学反应原理** | 有效碰撞与活化能动画、化学平衡移动、电离与水解、原电池、电解池 |
| 🔬 **化学实验演示** | 过滤、蒸馏、萃取分液、中和滴定、氯气制备等原理动画与易错点提示 |

## 🚀 打开方式

1. 双击 `index.html` 即可在浏览器打开（无需安装、无需联网依赖以外的任何环境）；
2. 或直接访问在线站点：**https://wujingxiaxiaolin.github.io/chem-viz/**

> 3D 部分使用 Three.js（CDN 引入），无需 npm、无需构建。
